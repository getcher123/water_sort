## Реализовано в игре

- Три решаемых уровня, по шесть бутылочек и четыре цвета.
- Строго плоские профили B1F1: декоративные блики отдельно, жидкость обрезается по 2D-полигону и сохраняет горизонтальную поверхность при наклоне.
- Выбор бутылки и переливание непрерывного верхнего слоя, допустимые цели, блокировка ввода во время анимации, атомарное изменение модели.
- Отмена хода, подтверждение перезапуска, пауза/справка, победа и переход на следующий уровень.
- Мышь, touch и клавиатура. Сброс устаревших касаний при смене состояния, автопауза при потере фокуса.
- Сохранение выбранного/завершённых уровней; незаконченная раскладка не восстанавливается.

## Сборка и эксплуатация

- Godot 4.6.3 stable, экспортные шаблоны 4.6.3.stable.
- Node 24 в CI, Node 22+ локально. Зависимостей npm нет.
- `npm test` — импорт, модель и контроллер.
- `npm run build` — те же тесты, экспорт и упаковка.
- `npm run test:loader` — транспортный тест готового экспорта.
- `npm run serve` — локальный HTTP на 127.0.0.1:4173.
- `GODOT_BIN` поддерживается тестами и сборкой.
- Workflow `.github/workflows/pages.yml`: PR только проверяет, main публикует после успешной сборки.
- Исходники хранятся в main; dist и engine/templates не коммитятся.

## Следующие шаги

1. Поддерживать `main` как источник публикации; после изменений дождаться зелёного workflow.
2. Проверить на физическом телефоне touch, Safari/Firefox/WebView и ориентацию экрана.
3. Пройти уровни 2–3 вручную в браузере; автоматический контроллер уже прошёл все три.
4. Android/SDK выполнять отдельным согласованным пакетом, не смешивая его готовность с Web-деплоем.

## Границы прототипа

Android APK/AAB, Kotlin-плагин и реальный Lumeriq SDK не входят в этот Web-деплой и не объявляются проверенными. Физика жидкости визуальная 2D, без тяжёлой гидродинамики. Дальнейшая работа по Android/SDK — отдельный пакет.
